# 12: Evidence com link a partir do Project

**What to build:** O Client se convence olhando o Project e a página lhe oferece o Service
que aquilo comprova, com escopo e faixa de preço, num clique. Fecha o beco sem saída de
hoje: Evidence é declarada do lado do Project, mas só navega no sentido Service → Project —
o modal de Service já lista os Projects que o comprovam, e o Project não tem o caminho de
volta.

O site existe para converter visitante em Client e os Projects são a prova dos Services. Hoje
a prova não leva à coisa que se pode contratar.

**Blocked by:** 08 (o destino precisa existir), 11 (o link precisa de um lugar no topo para
morar).

**Status:** ready-for-agent

- [ ] A página do Project lista os Services que ele comprova, derivados de Evidence
- [ ] Clicar num deles leva ao detalhe daquele Service, com Tiers e faixa de preço visíveis
- [ ] Um Project que comprova mais de um Service lista todos
- [ ] A navegação funciona no desktop e no celular
