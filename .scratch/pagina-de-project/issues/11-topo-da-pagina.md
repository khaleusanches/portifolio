# 11: Topo — Marks em destaque, Stack discreto, parágrafo de abertura

**What to build:** O Client descobre que tipo de sistema é este antes de ler um parágrafo.
Marks — o posicionamento editorial que a Brand atribui ao Project — passa a existir na tela
com o acento da marca. Hoje é um campo morto: está preenchido para todos os Projects e nunca
foi renderizado em lugar nenhum do site.

O Stack fica cinza, como ficha técnica discreta, e nunca recebe o acento. Dois motivos: o
Client já leu o Stack no card antes de clicar, então destacá-lo aqui é dar o primeiro lugar
ao que ele acabou de ler; e com o mesmo peso visual os dois viram a mesma sopa de pastilhas,
o que faria a tela mostrar como uma coisa dois conceitos que o glossário distingue.

O parágrafo de abertura da Description dá contexto curto antes do detalhe.
